## Generation brief

The screenshots were produced with OpenAI ImageGen from authentic FiberPulse interface references. The brief required a premium Microsoft Store presentation, a dark navy and teal FiberPulse palette, restrained short English headlines, readable interface content, no invented controls, no unrelated claims, and a 16:9 full-width composition. The super-hero brief required abstract network and pulse artwork with the FiberPulse brand mark, a calm lower third, centered important detail, and no text or application UI.

The privacy screenshot was regenerated after review because the first proposal introduced a navigation element that was not present in the application.
