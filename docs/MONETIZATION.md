# FiberPulse monetization

FiberPulse keeps the consumer product free through native sponsorships and
approved affiliate links. The local agent never loads third-party advertising
JavaScript, pixels, images, or cookies, and the dashboard hides the placement
while a measurement is running.

## Activate one campaign

Set all of the following variables before starting FiberPulse:

```text
FIBERPULSE_SPONSOR_CAMPAIGN_ID=ethernet-cables-ph-2026
FIBERPULSE_SPONSOR_LABEL=Sponsored
FIBERPULSE_SPONSOR_HEADLINE=Improve your wired test setup
FIBERPULSE_SPONSOR_BODY=Compare certified Ethernet cables from an approved FiberPulse partner.
FIBERPULSE_SPONSOR_CTA=View partner offer
FIBERPULSE_SPONSOR_URL=https://approved-partner.example/path?affiliate_id=YOUR_ID
```

The URL must use HTTPS. Never place account numbers, test results, IP addresses,
provider complaints, or profile data in the URL. Affiliate and sponsor terms
must explicitly allow software/application traffic before activation.

## Commercial model

1. Start with an approved Philippine marketplace affiliate campaign for useful,
   provider-neutral equipment such as Ethernet cables and UPS devices.
2. Sell one clearly disclosed fixed sponsor slot by country after the online
   account platform has sufficient traffic.
3. Keep ISP rankings, diagnostics, complaint thresholds, and test-server choice
   completely independent from commercial relationships.

Google AdSense must not be inserted in the desktop agent: its program policy
prohibits AdSense code inside software applications. AdSense may be evaluated
separately for a public, content-rich FiberPulse website after domain approval,
privacy disclosures, and the required consent platform are in place.
